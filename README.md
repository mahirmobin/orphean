##  Advanced Mechanics
- **True 3D Spatial Carousel**: Orphean strips primitive timeline layouts interpolating Android's native `HorizontalPager`. Navigating tracks rotates graphics physically on a strict 22° pitch, dynamically tweaking depth tracking to provide immersive rotation mechanics synced with queue bounds.
- **Physical Boundary Perimeter Scrubbing**: Scrub linear tracks exclusively by dragging digit inputs precisely along the circumference of the outer artwork border, complete with glowing track nodes responding immediately without timeline lag limits.
- **Automated Asynchronous Crossfading**: Settings seamlessly bridge natively onto `PlayerController` layers orchestrating overlapping volume decays spanning target configuration intervals (0.0f - 1.0f) dropping hard audio breaks definitively across local listening states.
- **Parametric Filtering Utilities**: Ignore ringtones mapping native boundaries screening sub-30-second logic dropping local system sounds elegantly out of valid queue lists globally.

## Architecture & Data Constraints
- **Offline First**: All configurations execute locally tracking internal storage utilizing pure `MediaStore` SQL structures aggregating song indices without web connections.
- **Hilt & Dependency Tracking**: Repositories abstract persistence configurations wrapping `SettingsRepository` logic gracefully driving crossfades decoupled straight off UI fragments.
- **Media3 ExoPlayer Configuration**: Media parsing targets natively implement robust AndroidX MediaSession architecture assuring background synchronization mapping accurately via `MediaBrowser` caches locking native playbacks.
